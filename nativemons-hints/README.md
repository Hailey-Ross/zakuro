# Shared hints for nativeMons

`<title id>-<code hash>.hints`: places where Zakuro had to interpret a game's code, which `nativemons-recomp`
adds to a player's own list before building that exact code (`nativemons-recomp id <rom>` prints both numbers).
They are addresses only, no game code.

They come from players who chose to share theirs from the launcher (an issue on Hailey-Ross/nativeMons), and are
merged here after a check: hex addresses only, one per line, for a title and code hash we already know.
